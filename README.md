# Azolla Mechanistic Biofilter Model V2.1

Reproducibility repository for the manuscript **An Identifiability-First Mechanistic Framework for Active Azolla Biofilters: Coupling Physiology, Mass Transfer and Model-Form Uncertainty**.

## Scope
This repository supports a literature-constrained mechanistic screening model for active *Azolla* biofilters used as a case study in indoor CO2 control. The work focuses on structural dependency, numerical verification, global sensitivity, practical identifiability, and hydraulic model-form uncertainty. It does **not** claim experimental validation of a fabricated Azolla device.

## Reproducibility files
- `scripts/sobol_converged_2048.py` — core mechanistic model plus nested Sobol analysis to N=2048 with 1000-resample bootstrap confidence intervals.
- `scripts/identifiability_diagnostic.py` — local sensitivity correlation and singular-value-decomposition diagnostic.
- `results/sobol_convergence_128_2048.csv` — first- and total-order sensitivity indices across N=128, 256, 512, 1024 and 2048.
- `results/local_sensitivity_parameter_correlation.csv` — parameter-sensitivity correlation matrix.
- `results/svd_singular_values.csv` — singular-value spectrum for the room-CO2 observation scheme.
- `results/manuscript_reference_outputs.csv` — central V2.1 model outputs and external plausibility benchmarks used in the manuscript.
- `notebooks/Azolla_Computational_Experiments_Colab.ipynb` — supporting/legacy computational-experiments notebook retained for provenance; headline V2.1 results are generated by the scripts above.
- `requirements.txt` — Python dependencies.
- `CITATION.cff` and `.zenodo.json` — citation and Zenodo deposition metadata.

## Reproducibility
The converged global sensitivity analysis uses a scrambled Sobol low-discrepancy sequence with nested base sample sizes N = 128, 256, 512, 1024 and 2048, together with 1000 bootstrap resamples for confidence intervals. The local practical-identifiability diagnostic uses ±1% central finite differences around the reference parameter vector and the 30-min room CO2 trajectory at 30-s resolution.

Run from the repository root with Python 3:

```bash
pip install -r requirements.txt
python scripts/sobol_converged_2048.py
python scripts/identifiability_diagnostic.py
```

Generated machine-readable outputs are written to `results/`.

## Scientific interpretation
The code is intended for mechanism screening, dependency analysis, uncertainty characterization and measurement prioritization. The reported numerical outputs are conditional model results, not experimentally validated performance specifications for a fabricated Azolla biofilter.
